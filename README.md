# 의성 지오트립 — 사용 설명서

고등학생이 의성 국가지질공원의 지질명소 12곳을 답사할 때 쓰는 학습용 웹앱입니다.
설치 파일 없이 이 폴더 그대로 웹에 올리면 휴대폰에서 앱처럼 쓸 수 있습니다(PWA).

> 이 앱은 의성군·의성 국가지질공원의 공식 앱이 아닌, 학교 수업용 비공식 학습 도구입니다.

## 1. 들어 있는 기능

Sagrada Familia Official 앱의 구성을 참고해 지질 답사에 맞게 옮겼습니다.

| Sagrada Familia 앱 | 의성 지오트립 |
|---|---|
| 티켓 구매·보관, 입장 | **답사 패스**: 이름표, 명소 12곳 스탬프(GPS 도착 인증 또는 퀴즈 만점), 배지, 완주 인증 |
| 오디오가이드(표준 45분 / 익스프레스 25분, 추천 동선) | **오디오 가이드**: 명소별 표준 해설(2~3분)과 핵심 요약(30초), 읽는 속도 조절, 추천 코스 5개 |

교과 학습용으로 추가한 것

- **기초 8단계**: 지구과학을 배운 적 없는 학생을 위한 입문 카드(암석 → 퇴적암 → 지층의 순서 → 퇴적 구조 → 화석 → 지질 시대 → 마그마 → 지질 구조). 읽기와 듣기 모두 됩니다.
- **개념 카드 20장**: 쉬운 설명 → 꼭 알아둘 낱말 → 한 줄 정리 → 한 걸음 더 → 2022 개정 교육과정 연결 순서. 11장에는 직접 그린 도해가 있습니다.
- **퀴즈 59문제**: 공통 과목 범위 9 + 지구과학 범위 12 + 심화 2 + 명소별 3문제(36), 쉬운 풀이와 오답 다시 풀기
- **탐구 도구**: 클리노미터(지층이 기운 각도와 방향), 공룡 속도 계산기(발 길이·걸음 간격 → 골반 높이·빠르기)
- 용어 사전 89개, 지질 연대표, 명소별 재미있는 이야기(설화·발견 일화)

### 처음 배우는 학생을 위한 장치

- 명소마다 **먼저 알아두기**(낱말 3~4개)가 있고, 음성 해설도 이 낱말 풀이부터 읽어 줍니다(오디오 가이드에서 끌 수 있음).
- 해설은 전문 용어가 처음 나올 때마다 뜻을 함께 말하고, 방위·각도 기호 대신 “남동쪽으로 40도”처럼 말로 풉니다.
- 오디오 가이드의 **기초 8단계 이어 듣기**(약 6분)는 이동하는 버스에서 듣기 좋습니다.

## 2. PC에서 미리 보기

`미리보기.bat`을 더블클릭하면 검은 창이 뜨고 브라우저가 `http://localhost:8080/`을 엽니다.
검은 창을 닫으면 끝납니다. (`index.html`을 직접 더블클릭해도 대부분 보이지만, 일부 기능은 위 방법에서만 작동합니다.)

PC에는 카메라 뒷면·GPS·기울기 센서가 없으므로 AR은 ‘연습 장면’, 클리노미터는 ‘직접 입력’으로 확인합니다.

## 3. 학생 휴대폰에서 쓰기

카메라·GPS·나침반은 **https 주소**에서만 작동합니다. 이 폴더의 내용을 정적 웹 호스팅에 올리세요.
서버 프로그램이나 데이터베이스는 필요 없습니다.

### 방법 A. GitHub Pages (권장: 무료이고 주소가 계속 유지됨)

화면은 영어입니다. 굵은 글씨가 눌러야 할 버튼 이름입니다.

1. github.com에서 계정을 만들고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**. 이름을 정하고(예: `uiseong-geotrip`), **Public**을 고르고, **Add README**를 켠 뒤 **Create repository**.
   무료 계정은 저장소가 공개(Public)여야 Pages를 쓸 수 있습니다. 앱의 코드와 글이 누구에게나 보인다는 뜻이며, 학생 기록은 올라가지 않습니다.
3. 저장소 화면에서 **Add file** → **Upload files**.
4. 탐색기에서 `geotrip-app` 폴더를 **열고**, 그 안의 파일과 폴더를 모두 선택(Ctrl+A)해 브라우저 창에 끌어다 놓습니다.
   폴더 자체가 아니라 **폴더 안의 내용**을 끌어야 `index.html`이 맨 위에 놓입니다. 한 번에 100개까지 올릴 수 있고 이 앱은 22개입니다.
   `.nojekyll`이라는 빈 파일도 함께 올리세요. GitHub가 파일을 불필요하게 변환하지 않게 해 줍니다.
5. 아래쪽에서 현재 브랜치(main)에 바로 저장하도록 둔 채 초록색 **Commit changes** 버튼을 누릅니다.
   파일 목록에 `index.html`과 `css`, `js` 폴더가 보이면 성공입니다. 폴더가 빠졌다면 크롬이나 엣지에서 다시 끌어다 놓으세요.
6. **Settings** → 왼쪽 메뉴 **Pages** → "Build and deployment"의 **Source**를 **Deploy from a branch**로, 브랜치를 **main**, 폴더를 **/ (root)** 로 고르고 **Save**.
7. 길게는 10분쯤 뒤 같은 화면에 주소와 **Visit site** 버튼이 나타납니다. 주소는 `https://<계정 이름>.github.io/<저장소 이름>/` 모양입니다.

내용을 고칠 때는 저장소에서 파일을 열어 연필 아이콘으로 바로 고치거나, 고친 파일을 **Upload files**로 다시 올립니다(이름이 같으면 덮어씁니다).

### 방법 B. Netlify Drop (가장 빠름)

app.netlify.com/drop에 `geotrip-app` 폴더를 끌어다 놓으면 바로 주소가 생깁니다. 계정 없이 올린 사이트는 임시이므로, 계속 쓰려면 가입해서 내 사이트로 가져와야 합니다.
무료 요금제는 한 달 300크레딧이고 게시 한 번에 15크레딧, 전송량 1GB에 20크레딧이 듭니다(2026년 11월 기준).

### 주소가 생긴 뒤

1. PC 크롬에서 그 주소를 열고 마우스 오른쪽 버튼 메뉴의 QR 코드 만들기로 QR을 만들어 수업 화면에 띄웁니다.
2. 학생은 휴대폰 카메라로 QR을 찍어 크롬(안드로이드)이나 사파리(아이폰)로 엽니다.
   카카오톡 같은 앱 안에서 열리면 카메라·위치 권한이나 홈 화면 추가가 안 될 수 있으니 ‘다른 브라우저로 열기’를 누르게 하세요.
3. 브라우저 메뉴에서 **홈 화면에 추가**를 누르면 앱 아이콘이 생깁니다.
4. 출발 전 와이파이에서 한 번 열어 두면 해설·퀴즈·개요도·AR 연습·도구는 인터넷 없이도 작동합니다.

## 4. 현장에 가기 전 점검

- 처음 쓸 때 **카메라, 위치, 동작 및 방향** 권한을 묻습니다. 모두 허용해야 AR·스탬프·클리노미터가 됩니다.
- 음성 해설은 휴대폰에 설치된 한국어 음성으로 읽습니다. 기기마다 목소리가 다르고, 드물게 지원하지 않는 기기는 글로 읽습니다. 이어폰을 챙기게 하세요.
- 자석이 든 휴대폰 케이스는 나침반(방향 라벨, 지층이 기운 방향)을 틀리게 합니다.
- 스탬프 인식 범위는 명소마다 다릅니다(대부분 300~700m, 안계분지·금성산은 2km 이상). 위치가 안 잡히면 그 명소의 퀴즈 3문제 만점으로도 받을 수 있습니다.
- 의성 스트로마톨라이트는 산지가 비공개라서 **의성조문국박물관**에서도 도착 인증이 됩니다.
- 사전 답사 때 실제 위치에서 스탬프와 AR을 한 번씩 확인해 보시길 권합니다.

## 5. AR 렌즈가 하는 일과 하지 않는 일

- 하는 일: 카메라 화면(또는 불러온 사진, 연습 장면) 위에 그 명소의 **관찰 포인트 설명**을 띄우고, 학생이 찾은 곳을 눌러 **이름표**를 붙입니다. **발자국 틀**(용각류·조각류·수각류)을 겹쳐 종류를 가리고, **경사 가이드**로 겉보기 경사를 재고, GPS·나침반으로 금성산 같은 먼 대상의 **방향 라벨**을 보여 주며, **시간 여행**으로 과거 환경 애니메이션을 겹칩니다. 겹친 화면은 그대로 찍혀 조사 노트에 저장됩니다.
- 하지 않는 일: 카메라 영상 속 암석을 **자동으로 인식해 판독하지는 않습니다.** 어느 명소인지는 GPS 또는 학생의 선택으로 정하고, 무엇이 어디 있는지는 학생이 직접 찾아 표시합니다(관찰 활동이 되도록 의도한 설계입니다). 사진을 보내면 AI가 분석해 주는 기능은 서버가 필요해 넣지 않았습니다.

## 7. 내용 고치기

글과 문제는 모두 `js` 폴더의 데이터 파일에 있습니다. 메모장으로 열어 따옴표 안의 글만 고치면 됩니다.

| 파일 | 내용 |
|---|---|
| `js/data-sites-1.js`, `js/data-sites-2.js` | 명소 12곳: 요약(`quick`), 먼저 알아두기 낱말(`words`), 해설(`narr`), 관찰 포인트(`look`), 이야기(`story`), 연결할 개념 카드(`links`), 탐구(`inquiry`), 퀴즈(`quiz`), 좌표(`lat`, `lon`), 인증 반경(`radius`, m) |
| `js/data-study.js` | 과목 이름(`GEO.subjects`), 개념 카드, 용어 사전, 교과 퀴즈, 연대표, 추천 코스, 준비물·안전 수칙, 묻고 답하기 |
| `js/figs.js` | 개념 카드에 들어가는 도해(SVG) |

- 개념 카드 한 장의 모양: `lv`(`'base'`는 기초 단계, `'plus'`는 더 알아보기), `easy`(쉬운 설명 문단들), `words`(낱말과 뜻), `cur`(과목 `s`, 단원 `u`, 성취기준 코드 `c`, 설명 `x`), `deep`(한 걸음 더), `tip`(한 줄 정리), `where`(확인할 명소).
- 퀴즈 한 문제의 모양: `{ q: '문제', a: ['보기1', '보기2', …], k: 정답번호(0부터), why: '해설' }`. 보기(ㄱ·ㄴ·ㄷ)형은 `box: ['ㄱ. …', 'ㄴ. …']`를 추가합니다. 교과 퀴즈는 `lv`로 묶음을 정합니다(`'is'` 공통 과목, `'es'` 지구과학, `'plus'` 심화).
- 해설(`narr`)과 쉬운 설명(`easy`)은 음성으로도 읽으므로, 기호(N65°E, =, →)보다 말로 풀어 쓰는 편이 좋습니다.
- 고친 뒤 이미 배포한 앱에 반영하려면 `sw.js` 맨 위의 `geotrip-v2`를 `geotrip-v3`처럼 올려서 다시 올리세요. 학생 휴대폰은 앱을 두 번 열면 새 내용으로 바뀝니다.
